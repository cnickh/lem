# Lem-Clim!

For the actual lem readme please see https://github.com/lem-project/lem.

This is a very much work in progress port of lem onto the Clim backend. Currently suffers from very bad performance issues. I would not recommend that any one use this. 

However, those interested in testing and reporting bugs feel free or if you would like to help feel free to reachout. I am currently occupied with other projects so progress will be slow and sporadic. Also if you happen to be an expert on Clim efficiency please reach out I'd love to chat.
